# KM STOR — متجر ملابس وأحذية تجريبي

## المتطلبات
- Node.js إصدار 20 أو أحدث (يوصى بإصدار LTS).
- اتصال بالإنترنت لتحميل الحزم والخط والصور الخارجية.

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `km-stor` في VS Code.
3. افتح Terminal داخل VS Code.
4. نفّذ:
   ```bash
   npm install
   npm run dev
   ```
5. افتح العنوان الذي يظهر في الطرفية، غالبًا `http://localhost:5173`.

## بناء نسخة الإنتاج
```bash
npm run build
npm run preview
```
ستجد ملفات النشر داخل `dist/`.

## ما الذي يعمل؟
- تصميم عربي RTL متجاوب مع الهاتف والكمبيوتر.
- بحث وتصنيف وترتيب المنتجات.
- تفاصيل المنتج واختيار المقاس.
- إضافة المنتجات للسلة، وتعديل الكميات وحذفها.
- حفظ السلة في localStorage على الجهاز نفسه.
- نموذج طلب تجريبي مع الاسم والهاتف والولاية والعنوان وطريقة الدفع.
- توضيح صريح أن الدفع الإلكتروني والطلبات ليست متصلة بخادم في هذه النسخة.

## قبل البيع الحقيقي
- استبدل المنتجات والصور والأسعار التجريبية ببياناتك الفعلية.
- أضف backend و قاعدة بيانات لتخزين الطلبات والمخزون.
- أضف لوحة إدارة للمنتجات والطلبات.
- اربط مزود دفع معتمد ومتاح في الجزائر إذا أردت الدفع الإلكتروني، ولا تخزن بيانات البطاقات بنفسك.
- أضف سياسة الخصوصية والشروط والإرجاع وبيانات التواصل.
- راجع تكاليف التوصيل الحقيقية حسب الولاية.
- صور المنتجات الحالية من Unsplash وتحتاج اتصال إنترنت؛ استبدلها بصور منتجاتك عند الإطلاق.
